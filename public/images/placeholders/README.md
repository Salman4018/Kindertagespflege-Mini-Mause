# Image replacements

`playroom.svg` is an original generic placeholder and can be used without an external image
license. Replace it with an approved real photograph during Phase 11.

Recommended source dimensions are at least 1600 by 2000 pixels. Keep the subject near the center
so the image remains useful in its responsive arched crop. Use WebP or AVIF for final photographs
and retain meaningful localized alternative text in the content files.
